## 1. 開始使用

- **登入**:輸入帳號密碼(多租戶的系統還要輸入管理員給你的**公司代碼**,瀏覽器會記住上次輸入的)。第一次登入或密碼被管理員重設後,必須先**變更密碼**(至少 8 個字元,需同時含英文字母與數字)。
- **鎖定**:連續輸入錯誤密碼太多次,帳號會鎖定一段時間(約 15 分鐘),請稍後再試或請管理員解鎖。
- **逾時**:閒置一段時間後登入會自動延續;長時間未使用或被停用時會回到登入頁。
- **雙因素驗證(建議啟用)**:右上角選單 → **帳號安全**,用手機的驗證器 App(Google Authenticator、Microsoft Authenticator、1Password…)掃描 QR Code,輸入 App 顯示的 6 位數啟用,並**把備援碼存放在安全的地方**(只顯示一次、每組只能用一次)。啟用後登入要先輸入密碼、再輸入驗證碼;手機不在身邊時可改輸入備援碼。驗證碼連續輸錯會和密碼錯誤一樣被鎖定。手機遺失又沒有備援碼,請管理員到 系統管理 → 使用者 按「重設 2FA」。
- **首頁**:依你的權限顯示——今日與本月銷售(含本月前 5 大客戶)、待你審核的單據、庫存警示、應收應付(含逾期)、月結提醒。點數字可直接前往已篩選好的清單。
- **金額與數字**:帳上一律以新台幣(TWD)入帳;外幣單據同時保存原幣與新台幣金額。

## 2. 角色與權限(管理員)

權限在 **系統管理 → 角色權限** 設定,再到 **使用者** 指派角色。每個模組的權限分成幾層,**刻意讓不同的人負責不同層**(職責分離):

| 權限層 | 能做什麼 |
|---|---|
| 檢視 | 看清單與單據 |
| 開單 / 送審(write) | 建立、修改草稿、送審、作廢**草稿** |
| 核准(approve) | 核准、退回、取消核准、作廢待審 / 已核准的單據;訂單類另可結案、重開 |
| 過帳(post) | 過帳、反過帳(會異動庫存、產生應收應付與傳票) |

**開單的人不能核准、核准的人不能過帳**(除非角色同時給了這些權限)。超級管理員擁有全部權限。

**資料範圍**(每個角色一個):**全部**、**本部門**、**僅本人**。銷售相關(客戶、報價 / 訂單、出貨、收款單、應收、對帳單、帳齡)依**客戶的負責業務**判斷:
「僅本人」的業務只看得到自己負責的客戶與其單據,範圍外的單據對他而言「不存在」。沒有指定負責業務的客戶,只有「全部」範圍的人看得到。

**建議的角色配置**(依公司規模調整):

| 角色 | 建議權限 | 資料範圍 |
|---|---|---|
| 業務 | 客戶檢視、報價 / 訂單與出貨的開單 / 送審、應收與對帳單檢視、收款單開單 | 僅本人 |
| 業務主管 | 業務的權限 + 報價 / 訂單 / 出貨 / 收款單的核准 | 本部門 |
| 採購 | 供應商、採購單與進貨單的開單 / 送審、未交貨清單 | 全部 |
| 倉管 | 料品、倉庫檢視、庫存單據開單 / 送審、進貨 / 出貨的**過帳**、現有量 | 全部 |
| 會計 | 應收應付全部、收付款單過帳、傳票、會計報表、對帳檢查、會計期間 | 全部 |
| 主管 / 老闆 | 各類單據的**核准**、報表檢視、關帳與月結 | 全部 |

信用額度需要另外的權限(`客戶 → 設定信用額度`),避免負責該客戶的業務自己調高額度。**所有新增 / 修改 / 動作都會記錄在 系統管理 → 稽核日誌**,且無法修改或刪除。

### 2.0 雙因素驗證政策(管理員)

- 系統管理 → **公司資料** 的「雙因素驗證」開關:開啟後**所有使用者**登入後必須先完成設定才能使用系統,也不能自行停用。**開啟前,你自己必須已啟用**(否則系統不會讓你開,避免把自己鎖在外面)。
- 使用者遺失手機又沒有備援碼:系統管理 → 使用者 → **重設 2FA**,對方的備援碼作廢、既有登入失效;公司有要求時,對方下次登入須重新設定。
- 密鑰以加密儲存。**請勿更換** `TOTP_ENCRYPTION_KEY`(沒獨立設定時是 JWT_SECRET),更換後所有已啟用者都無法驗證,須逐一重設。

### 2.1 多層簽核(管理員)

> 「工單」也可設定簽核規則,金額以**加工費**計。

預設每張單據只需要**一層核准**(具該單據核准權限的人)。金額大的單據要更高層級把關時,到 **系統管理 → 簽核規則** 新增規則:

- 選單據類型(採購單、進貨單 / 進貨退出、報價單 / 訂單、出貨單 / 銷貨退回、收款單、付款單)與**金額門檻**(本位幣含稅,單據金額 ≥ 門檻才適用;同一類型有多條時取門檻最高且不超過單據金額的那一條)。
- **第 1 層**固定是具該單據「核准」權限的人;**第 2 層起**依序指定角色(最多再加 4 層)。擔任層級的角色必須有該單據的核准權限,否則系統不會接受。
- **依部門分流**:規則可選「適用部門」(留空 = 全公司)。送審時依**送審者所屬部門**找規則:先看他的部門與上層部門(越接近越優先),都沒有適用的部門規則,才用全公司規則。例如「業務部」規則只管業務部同仁送審的單據,其他部門仍走全公司規則。送審者沒有部門時只適用全公司規則。
- **會簽 / 或簽**:第 2 層起,每一層可選**多個角色**(最多 5 個),選 2 個以上時再選簽法——**或簽**:任一角色有人核准,這一層就通過(其餘角色免簽,進度顯示「免簽」);**會簽**:每個角色都要各有一人核准才通過(進度顯示「已 x/y」,會簽至少 2 個角色)。同一個角色不能出現在同一規則的兩個層級。一個人同時具備多個角色時,在會簽層**只能簽一格**,系統會優先替他填「較少人能簽」的那一格。超級管理員在會簽層也只能簽一格(仍是一人一票)。
- 單據**送審時**才決定流程並記下來:之後修改或刪除規則,**不影響已送審的單據**;單據被退回、取消核准或作廢後再送審,會依當時的規則重新決定。
- **同一個人不可核准同一張單據的兩個層級或兩格**(包含超級管理員)——所以規則所需的每一層至少要有不同的人。
- 單據頁上方會顯示「簽核流程」與每層的核准者與時間。輪不到你核准時,「核准」按鈕不會出現。全部層級核准完,單據才變成「已核准」;中途任何一層都可以「退回」,退回後所有層級重新來過。
- 沒有適用規則的單據維持單層核准。
- **庫存單據**(調整 / 調撥 / 盤點)也可設簽核規則,三種共用一組;因為沒有金額,**門檻一律填 0**。
- **簽核代理人**:選單「簽核代理人」。出差 / 休假前設定代理人與起迄日,期間內代理人可以核准你有權限、或由你的角色負責的那一層(資料範圍仍以代理人自己為準),單據頁會顯示「(代 你)」。你和你的代理人視為同一個人:代理人核准了第 1 層,你不能再核准第 2 層。可隨時「終止」。管理員(有簽核規則維護權限)可替他人設定、勾選「顯示全公司」檢視。
- **待我核准**:有任一核准權限的人,選單會出現「待我核准」,列出**現在輪到你核准**的單據(含目前是第幾層),點單號進入單據核准。業務類單據只看得到自己資料範圍內的;你已核准過的前一層、或不是你角色負責的層級不會出現。

**Email 通知**:管理員在伺服器設定 Gmail(`SMTP_USER`、`SMTP_PASSWORD` 填 Google「應用程式密碼」,詳見 README)後,系統會寄信給有填 email 的使用者:①輪到你核准的單據(含你是代理人時);②未兌現票據 3 天內到期或已逾期;另有三種**每週一封**的摘要:③低於安全庫存的料品(有庫存檢視權限者)、④已過期或 30 天內到期且有庫存的批號(有庫存檢視權限者)、⑤逾期未收的應收筆數與金額(有收款過帳權限且資料範圍為「全部」者)。信件只提示並附連結,單據類不含內容。每個人可在右上角帳號選單的「通知設定」個別關閉各類通知(預設全開),並可按「寄一封測試信給我」確認設定是否正常。

## 3. 單據通則

### 3.1 狀態流程

```
會過帳的單據(進貨、出貨、退回退出、收款、付款、庫存單據):
  草稿 ──送審──▶ 待審 ──核准──▶ 已核准 ──過帳──▶ 已過帳
   ▲             │退回          │取消核准          │反過帳(回到已核准)
   └─────────────┘←─────────────┘
  草稿 / 待審 / 已核准都可以「作廢」;已過帳要先反過帳才能作廢

不過帳的單據(報價單、訂單、採購單):
  草稿 → 待審 → 已核准 ──結案──▶ 已結案 ──重開──▶ 已核准
```

- **只有草稿可以修改。** 已送審的單據要改,請先「退回」(或取消核准)回到草稿。
- **作廢後無法復原**,但紀錄保留、單號不再使用。
- 按鈕只會出現「目前狀態、而且你有權限」可以做的動作。
- **「他人已修改」**:兩個人同時改同一張單據時,後存檔的會被擋下,請重新整理後再改(避免蓋掉別人的修改)。

### 3.2 單號

格式為「前綴 + 日期 + 流水號」,例如 `PO202610080001`(採購單)、`SO…`(訂單)、`DN…`(出貨單)。前綴、日期格式與位數可在 **系統管理 → 單號規則** 調整——**開始開單後請不要再改**。

### 3.3 明細與金額

- 數量可選任一**換算單位**(例如箱),系統保存換算倍數並同時算出基本單位數量。
- **單價一律是未稅**;行金額 = 數量 × 單價,依幣別小數位四捨五入;**稅額依整張單據的未稅合計計算**(不是逐行),所以合計與發票的算法一致。
- **外幣**:選了外幣,匯率會依單據日期自動帶入(取該日或之前最近一筆),可手動改;查不到匯率會提示,請到 基本資料 → 財務設定 補匯率。

### 3.4 從來源單據帶入(轉單)

- 採購單核准後按 **轉進貨單**;報價單核准後按 **轉訂單**;訂單核准後按 **轉出貨單**。
- 也可以在進貨 / 出貨 / 退出 / 退回單按 **從○○帶入**,挑選要帶入的明細。
- 帶入的明細,料品與單位跟著來源不能改;數量預設為剩餘量,可以改小(部分進貨 / 出貨),**不能超過剩餘量**。

## 4. 基本資料

| 項目 | 重點 |
|---|---|
| **料品** | 料號、品名規格、分類(樹狀)、**商品 / 服務**(服務類不管庫存,可用於運費等)、**基本單位**、單位換算(1 箱 = 12 個)、條碼、稅別、安全庫存。**料品一旦有庫存異動,不可再改基本單位與類型** |
| **倉庫** | 可設定「允許負庫存」;預設不允許,庫存不足就不能出貨 / 調出 |
| **客戶** | 統一編號(會驗證檢查碼)、多聯絡人 / 地址、幣別、稅別、付款條件、**信用額度**(0 = 不限)、**負責業務**(決定資料範圍) |
| **供應商** | 同客戶,另有匯款資訊 |
| **財務設定** | 幣別(新台幣為本位幣)、匯率(依日期)、稅別(應稅 / 零稅率 / 免稅)、付款條件(月結 / 天數,用來算應收應付的到期日) |

停用不等於刪除:已停用的料品、客戶等不能再被新單據使用,但舊單據與歷史報表不受影響。

## 5. 採購

**流程**:採購單 → 核准 → 進貨單(可分批)→ 過帳 →(必要時)進貨退出單。

1. **採購單**:供應商、入庫倉、預定交貨日、明細。核准後才能轉進貨。已核准的採購單不會動庫存。
2. **進貨單**:可由採購單轉入(分批進貨),也可不經採購單直接進貨。可登錄供應商的**發票號碼**。
3. **過帳**:
   - 商品類明細**增加庫存**,並記下入庫成本(明細新台幣金額 ÷ 基本單位數量);服務 / 費用類明細不入庫。
   - 產生**應付帳款**(依付款條件算到期日)與**傳票**(借 存貨 / 費用、進項稅額,貸 應付帳款)。
4. **未交貨清單**:已核准採購單中還沒交齊的明細,可只看逾期(預定交貨日已過)。
5. **結案**:供應商不會再交剩下的數量時,把採購單結案;剩餘未交量就不再追蹤。可重開。
6. **進貨退出單**:從已過帳的進貨單帶入,不能超過可退量。過帳後減少庫存、沖減應付(負數的應付)並產生傳票。退出**不會**把數量補回採購單的未交量。

開採購單 / 進貨單時,選好供應商後再選料品,系統會自動帶入該供應商同幣別的**最近進價**(與當時的單位),可再修改。

**採購報表**(選單「採購報表」):選期間後可看「依供應商排行」「依料品排行(含平均單價)」「明細」,可匯出 Excel;只計已過帳的進貨與退出。排行列可點進該供應商(料品)的明細。

**反過帳的限制**:進貨單已有退出單、或應付已被付款單引用(含草稿)時不能反過帳,請先處理下游單據;採購單已有進貨單時不能取消核准或作廢,不再進貨請改用「結案」。

## 6. 銷售

**流程**:報價單 → 訂單 → 出貨單(可分批)→ 過帳 →(必要時)銷貨退回單。

1. **報價單**:有有效期限;核准後可「轉訂單」(整張複製並記錄來源報價)。報價單不保留庫存。
2. **訂單**:可填客戶單號、預定出貨日。
   - **可用量**:明細旁顯示「現有量 − 其他已核准訂單尚未出貨的量」,不足時以紅字提示,**但不會擋單**(允許缺貨接單);真正出貨過帳時庫存不足才會被擋。
   - **信用額度**:**核准**時檢查「未收應收 + 其他已核准訂單未出貨金額(含稅)+ 本單」是否超過客戶額度,超過就不能核准,訊息會列出各項金額。額度為 0 表示不限。
3. **出貨單**:由訂單轉入或從訂單帶入,分批出貨。**過帳**後扣庫存、產生**應收帳款**與**傳票**(借 應收帳款,貸 銷貨收入、銷項稅額)。
4. **發票**:出貨單過帳**前後都可以**「登錄發票」(格式:2 碼英文 + 8 碼數字,同公司不可重複);可在出貨單清單篩選「未登錄發票」追蹤。作廢的單據可釋出號碼。
5. **未出貨清單**:已核准訂單中還沒出齊的明細,可只看逾期。
6. **銷貨退回單**:從已過帳的出貨單帶入;過帳後加回庫存、沖減應收(負數)並產生傳票。
7. 銷貨**成本**不在出貨時算,於**月結成本**時依月加權平均成本計算並拋傳票(見第 10 節)。

業務只能看到並開自己負責的客戶的單據;核准與過帳由有該權限的人處理。

**銷售報表**(選單「銷售報表」):選期間後可看「依客戶排行」「依料品排行」「明細」,可匯出 Excel。只計已過帳單據、本位幣未稅,退回以負數扣除。**毛利**要等該月份「月結成本」完成才會計算(成本 = 數量 × 當月平均成本);尚未月結的銷售額會另外提示、不計入毛利。業務只看得到自己負責客戶的資料。在排行列上點一下,會跳到該客戶(料品)的明細,可按標籤的 × 取消篩選。

**售價表**(選單「售價表」,維護需「維護售價表」權限):可設「所有客戶的一般價」或「某客戶的專屬價」,另可設數量門檻(基本單位數量 ≥ 才適用)與有效期間、幣別。開報價 / 訂單 / 出貨時選好料品,單價若空白,系統依「客戶專屬價 → 一般價(同層取門檻最高者)→ 料品建議售價」自動帶入,仍可手動修改。

**含稅單價輸入**:開單頁稅別旁勾選「含稅輸入」後,單價欄改以含稅金額輸入,系統自動換算成未稅儲存(單據金額仍以未稅單價計算)。

**信用額度超額覆核**:訂單核准超過客戶信用額度時預設會被擋下;持有「超額度覆核」權限者按核准時會跳出視窗,填寫原因後可強行核准,原因會記在稽核紀錄。

**列印**:傳票、庫存單據、採購 / 銷售單、收付款單與工單的標題旁有「列印」鈕,會隱藏選單與操作按鈕後呼叫瀏覽器列印(可另存 PDF)。

## 7. 庫存

- **現有量**:各料品在各倉庫的數量;可篩「低於安全庫存」(依料品在所有倉庫的合計判斷)。點料號可看**料品異動明細**(期初結存 + 每筆異動 + 累計結存)。
- **收發存**:選期間,看每個料品的 期初 + 收 − 發 = 期末。
- **庫存單據**:
  - **調整單**:直接增減數量(負數為減少),用於報廢、盤盈虧以外的調整。
  - **調撥單**:從調出倉移到調入倉,兩邊同時異動。
  - **盤點單**:建立時系統依倉庫目前的現有量**快照帳面數**並**凍結該倉庫**(盤點單過帳或作廢前,該倉庫不能有其他庫存異動);填入實盤數後送審、核准、過帳,系統依差異調整庫存。盤點明細**只能新增、不能刪除**(避免把盤虧藏起來)。
- 庫存不足時過帳會失敗,訊息列出每個不足的料品、現有量與需要量。
- **所有庫存異動都寫入流水帳,只增不改**;反過帳是產生反向分錄,不是刪除。

### 7.1 批號與效期

適用有保存期限的商品(食品、藥品、化妝品…)。**在料品設定「批號管理」**:不管理(預設)/ 管理批號 / 管理批號與效期。**料品有庫存異動後就不能再改**,所以請在開始作業(含匯入期初庫存)前決定好。

- **入庫要輸入批號**:進貨單、銷貨退回單、庫存調整單(數量為正)、期初庫存匯入。管理效期的料品,**新批號另須輸入效期**;批號已存在時效期可省略(沿用)。批號一律轉大寫、不可含空白、最多 40 字;同一個批號的效期只有一個。
- **出庫預設先到期先出**:出貨單、進貨退出單、調整減少、調撥的批號欄位可以留空,系統自動從最早到期的批號出,庫存不夠就拆到下一個批號;也可以手動指定批號。已過帳的單據會顯示實際出了哪些批號。
- **過期批號不能出貨**:自動分配會略過已過期的批號(庫存不足時,訊息會說明另有過期庫存);手動指定過期批號出貨也會被擋。**報廢請用庫存調整單(數量為負)**,這時可以出已過期的批號。調撥、進貨退出、反過帳不受效期限制。
- **批號庫存不能是負的**,即使倉庫設定允許負庫存。
- **調撥**沿用原批號;**反過帳**會還原到原本的批號。
- **盤點**:批號管理的料品每個批號一行,分別輸入實盤數。
- **銷貨退回**要指定退回的是哪個批號;進貨退出不填的話沿用被退進貨明細的批號。
- **查詢**:庫存 → **批號庫存** 列出各批號的現有量、效期與狀態(正常 / 即將到期 / 已過期),可篩選即將到期(天數可調)與已過期;點批號看**追溯**——這個批號從哪張單據進來、出給哪個客戶。首頁的**效期警示**列出已過期與 30 天內到期的批號。
- **匯入**:料品匯入範本有「批號管理」欄(空白 / 批號 / 批號與效期);期初庫存匯入範本有「批號」與「效期」欄,批號管理的料品每個批號一列。
- 成本仍依料品的月加權平均計算,**不分批號計價**。

### 7.3 儲位

適用倉庫內要分區管理的情況(貨架、貨位)。**在倉庫設定開啟「啟用儲位」,再按「儲位 → 管理」新增儲位**(代號限英數字與 `. _ -`,例如 A-01-02)。**倉庫有庫存時不能切換**,所以請在開始作業(含匯入期初庫存)前決定好。

- **入庫要指定儲位**:進貨單、銷貨退回單、庫存調整單(數量為正)、工單的成品入庫、調撥的調入儲位。沒啟用儲位的倉庫不會顯示儲位欄,也不能指定。
- **出庫儲位可以留空**:出貨單、進貨退出單、調整減少、調撥、工單領料。留空時系統**先從庫存最多的儲位出**,不夠就拆到下一個儲位;也可以指定儲位。
- **儲位庫存不能是負的**,即使倉庫設定允許負庫存;指定儲位出庫超過該儲位的庫存會被擋。
- **同一倉庫的儲位之間移動**用**調撥單**:調出倉與調入倉選同一個(啟用儲位的)倉庫,各行指定調出與調入儲位(須不同)。
- **反過帳**會還原到原本的儲位。
- **盤點**:啟用儲位的倉庫也可以開盤點單。明細是**每個有庫存的(料品、批號)× 儲位一行**,帳面數是該儲位的現有量;盤盈到沒有帳面的儲位,請新增一行(儲位必填)。
- **查詢**:庫存 → **儲位庫存**列出各儲位放了哪些料品與數量。
- **批號與儲位一起記錄**:批號管理的料品出庫,批號與儲位都不指定時先到期先出、同批號內庫存多的儲位先出;只指定批號就從放著該批號的儲位出;只指定儲位就從該儲位裡先到期的批號出;兩者都指定但該儲位沒有該批號會被擋。批號追溯頁會顯示這個批號目前放在哪些儲位。
- 有異動紀錄的儲位只能停用、不能刪除;有庫存的儲位不能停用。
- **升級注意**:從舊版升級時,已在啟用儲位倉庫中的批號庫存會由系統**推算**放在哪個儲位(舊版沒有記錄這個對應),請升級後盤點一次,把帳面修正為實際擺放。

## 7.2 生產:BOM 與工單

**BOM(物料清單)**(生產 → BOM):每個成品一份,列出「產出 N 個成品」需要的材料與用量(**基本單位**)。每個材料可設**損耗率(%)**:BOM 上的用量是淨用量,開工單時系統自動加成(用量 × (1 + 損耗率)),例如用量 25、損耗率 10% → 領料預設 27.5;領料明細仍可手動調整。

**替代料**:BOM 的每個材料下可按「+ 替代料」加最多 5 個替代料,並填替代比例(1 單位主料 = 幾單位替代料,例如 1.5)。開工單、系統依 BOM 展開領料後,有替代料的材料會出現「替代料」選單,選擇後該行自動換成替代料並依比例換算用量;可再換回主料。系統不會自動換料,也不會因缺料自動選替代料。

**BOM 版本**:同一成品可建立多份 BOM,各有**生效日**(留空 = 一直有效)。開工單時系統依**工單日期**選用「已生效且啟用中」之中生效日最晚的一份;想換配方,新增一份有新生效日的 BOM 即可,舊工單不受影響。同一成品的同一個生效日只能有一份。成品與材料都必須是啟用的商品類料品;材料不可重複、不可是成品自己,**也不可循環**(例如成品 A 用到 B,B 的 BOM 就不能再用 A)。半成品有自己的 BOM 與工單,這樣就能串成多階。停用的 BOM 不能開工單;已有工單用到的成品不能刪除 BOM,請改為停用。

**工單**(生產 → 工單):可一次完工,也可**分批完工**(見下方第 3 點)。

1. **開單**:選成品、完工數量、成品入庫倉與領料倉、加工費(人工與製造費用,本位幣)。**系統依 BOM 自動展開領料明細**(用量 × 完工數量 ÷ 產出量),可以手動調整實際用量、增減材料;明細會顯示領料倉現有量,不足的以紅字提示(不會擋存檔,完工時才會擋)。批號管理的材料可指定批號(空白則先到期先出);成品是批號管理的,要填成品批號(與效期)。
2. **流程**:草稿 → 送審 → 核准 → **完工**(狀態沿用單據的核准流程,權限分「開單 / 核准 / 完工」三層)。
3. **完工**:同一個動作內扣除材料庫存並把成品入庫;材料不夠就整張失敗、庫存不變。**反完工**會沖銷這兩批異動(成品若已被領用或出貨,庫存不足會失敗;該月已月結成本也不能反完工)。
   **分批完工**:工單核准後,在工單頁下方「分批完工」按**完工回報**,填完工日期、本次完工量(預設為剩餘全部)與本次加工費(預設依比例);領料預設依「本次完工量 ÷ 計畫數量」分攤,可逐筆改用量、批號、儲位。**回報即過帳**(當下領料並成品入庫,不再另外簽核,需要「完工」權限)。累計完工量達計畫數量時工單**自動結案**;只做了一部分也可按**短交結案**,剩餘計畫不再生產。**作廢**某筆完工回報會沖銷該批入庫與領料(成品已出貨或該月已月結會失敗),已結案的工單會退回「已核准」。**有完工回報的工單不能再用「完工 / 反完工 / 取消核准 / 作廢」**,要先作廢全部回報。分批完工的加工費以各次回報填的金額、依回報日期計入月結。
4. **成本**:完工當下單據上不會有單價。**月結成本時**才計算:成品成本 =(領用材料量 × 材料當月平均成本)+ 工單加工費,併入成品的平均成本;領料以材料平均成本計價,但**不算銷貨成本**。月結明細有「領料量 / 領料金額」欄。
5. **會計**:材料轉成品的存貨總額不變,所以不產生傳票;**加工費**在月結時以一張傳票由「加工費轉出」(5103)轉入存貨(借 存貨、貸 加工費轉出),實際發生的人工與製造費用仍照一般方式記為費用。拋轉科目可在「拋轉規則」調整。
6. **限制**:沒有在製品(WIP)與委外加工;同月份內材料與成品互相循環使用(A 用到 B、B 又用到 A)時月結會報錯,請檢查工單。

**標準成本與成本差異**(庫存 → 標準成本、成本差異):為成品設定「目標單位成本」(基本單位,只做管理用,**不入帳**)。月結成本後,「成本差異」選月份,會列出當月完工的成品:實際單位成本(月結算出)、標準單位成本、差異金額與百分比。**差異 = 實際 − 標準,正數(紅)表示實際比標準貴**。當月還沒月結的,實際成本未定,會顯示「該月尚未月結」。維護標準成本需要「維護標準成本」權限。

**標準成本版本**:標準成本頁每個料品有「版本」鈕,可新增**不同生效日**的標準成本(例如 10/1 起改 450);差異報表依**每筆完工日**取當時有效的版本。直接在欄位輸入的是「一直有效」的基準版本;欄位清空會清掉全部版本,要只刪某一版請在版本視窗刪除。完工日前沒有任何有效版本的視為未設標準成本。

**差異拆解**:「成本差異」每個成品可再看**用量差異、價格差異、加工費差異**(三者相加 = 總差異),點最左邊的箭頭展開可看各材料的標準 / 實際用量與單價。標準用量依 BOM(含損耗率)計;材料標準單價取該材料在「標準成本」設定的值,沒設就以實際單價計(價格差異為 0);標準加工費 = 成品標準成本 × 數量 − 標準材料成本。替代料不在 BOM 內,會表現為用量差異。需月結完成且成品有設標準成本才有拆解;標準用量用期間結束日適用的 BOM,月中換過 BOM 的月份僅供參考。

**需求計算(MRP)**(生產 → 需求計算):算出「該生產或採購多少、最晚什麼時候下單」。系統**依交期分週**計算(畫面上可選 1~26 週,預設 8 週):每週的預計庫存 = 上週預計庫存 + 該週預計入庫(採購單的預定交貨日、未完工工單的預定完工日)− 該週需求(訂單的預定出貨日、未完工工單領料、上層建議生產帶下來的需求);沒填日期或已逾期的算在第 1 週,超過範圍的算在最後一週。預計庫存低於**安全庫存**就在那一週建議補貨(現有庫存為全部倉庫合計):有 BOM 的料品建議**生產**,並依 BOM(含損耗率)把材料需求帶到下一階;沒有 BOM 的建議**採購**。只是建議,不會自動開單;預設只列需補的料品,取消勾選可看全部;點每列左邊的箭頭可看各週的需求、入庫、建議補貨與預計庫存。

**MRP 計畫參數**(生產 → MRP 計畫參數):每個料品可設**前置時間(天)**、**最小訂購 / 生產量**與**批量倍數**(基本單位;全部填 0 = 不限制,需要 BOM 維護權限才能修改)。建議補貨量先補到最小量,再進位到批量倍數(例如缺 5、最小量 20、批量 8 → 建議 24)。**最晚下單日** = 需要補貨那一週的開始日 − 前置時間;如果已經早於今天,會標示「**來不及**」,並從今天算起(材料的需求也從今天下單那一週開始算)。有 BOM 的料品,前置時間就是生產前置;它的材料會依成品的下單日再往前推。同一週內不分先後,入庫視為週初到貨;不處理假日與工作日。

## 8. 收款與付款

**收款單**(客戶)與**付款單**(供應商)流程相同:草稿 → 送審 → 核准 → **過帳**(才會真正沖銷)。

1. 選客戶(供應商)與幣別,按 **選擇未沖應收 / 應付**,勾選要沖的帳款;每筆預設沖全額,可改成部分金額。一張單可沖多筆。
2. **只能沖同一個對象、同一個幣別**的帳款;金額不可超過該筆未沖餘額。
3. **負數帳款**(銷貨退回、進貨退出產生的)可以和正數互抵,例如貨款 4,200 扣掉退貨 1,050,一次收 3,150;**合計不可為負**。
4. 過帳時才扣帳款的未沖餘額;反過帳會還原。同一筆帳款被兩張單同時沖,後過帳的會被擋下(以免超沖)。
5. 被收付款單引用的帳款(**包含草稿、待審**),來源的出貨單 / 進貨單不能反過帳,請先作廢或反過帳收付款單。
6. 收付款**過帳也會產生傳票**(借 現金 / 銀行存款,貸 應收帳款;付款相反);現金方式用現金科目,其他方式用銀行存款科目。

**外幣收付款匯兌損益**:外幣收付款過帳時,現金 / 銀行依「收付款日」的匯率換算,和帳款入帳時的本位幣金額相差的部分,記入「兌換利益 4902」或「兌換損失 7102」。該日以前必須有匯率,否則無法過帳。期末外幣餘額重估不在範圍內。

**預收 / 預付款**(僅本位幣):收付款單可填「新增預收(預付)」,多收的金額記入 2121 預收款項(付款為 1151 預付款項),也可不選任何帳款,純粹預收。之後開單時填「抵用預收(預付)」即可拿餘額扣抵,畫面會顯示目前餘額;抵用不可超過餘額。預收已被抵用的單據不可反過帳。

**票據**:收付款方式選「支票」時,過帳先記入應收票據 1121(付款為應付票據 2141)並登錄票據(票號填在「備查」、可填支票到期日)。選單「應收票據 / 應付票據」列出票據與到期日(逾期會標示),到期入帳後按「兌現」才轉入銀行存款,可「取消兌現」。**退票**:票據未兌現時,直接將該收付款單反過帳即可,帳款回到未沖狀態。需有收付款的過帳權限。

**對帳單**:選對象、幣別與期間,列出期初餘額、各筆帳款與收付款、期末餘額,可列印(瀏覽器列印可另存 PDF)或「匯出 Excel」給客戶 / 供應商核對。
**帳齡分析**:本位幣、**回推到你選的截止日當天的未沖餘額**(只扣除收付款日期在截止日以前的沖帳),依到期日分成「未到期 / 逾期 1–30 / 31–60 / 61–90 / 90 天以上」,依客戶(供應商)彙總,用來催收與排付款。

## 9. 會計

### 9.1 自動拋轉的傳票

進貨、進貨退出、出貨、銷貨退回、收款、付款**過帳時自動產生已過帳的傳票**,與單據同時成功或同時失敗,不會出現「單據過帳了、傳票沒產生」;反過帳會自動產生**沖銷傳票**(借貸相反、沿用原日期)。

- 各分錄使用哪個科目,在 **會計 → 拋轉規則** 設定(預載台灣常用科目);調整只影響**之後**產生的傳票。
- 自動傳票**唯讀**,更正請由來源單據反過帳,系統會自動沖銷;傳票頁有「查看來源單據」連結。

### 9.2 手動傳票

用於薪資、租金、折舊等沒有業務單據的分錄:
草稿(可以暫存不平衡)→ **過帳**(借貸必須相等)→ 需要更正時**沖銷**。
- 每一行只填借方**或**貸方;金額為整數元;只能用**明細科目**(彙總科目不可記帳);可標註客戶 / 供應商 / **部門**做輔助核算(部門別損益依此統計)。
- **附件**:傳票存檔後,頁面下方「附件」可上傳原始憑證(PDF、PNG、JPEG、.xlsx,每個 5MB 以內、每張最多 10 個)。草稿可刪除附件;**已過帳的傳票附件是留存憑證,只能新增不能刪除**;已作廢的傳票不能再新增。
- **已過帳的傳票不能修改或刪除**(資料庫層面也禁止),更正一律用沖銷傳票(一張傳票最多被沖銷一次)。

### 9.3 會計科目

會計 → 會計科目。代號為 3–10 碼數字,建立後**代號不能改**;可設**彙總科目**(群組,不能直接記帳)與上層。**已有分錄的科目不能改類別或改成彙總**;被拋轉規則使用的科目不能停用。

### 9.4 會計報表

會計 → 會計報表:**試算表**(各科目期初、本期借貸、期末,並核對借貸是否平衡;點科目跳到總分類帳)、**總分類帳**(單一科目的明細與累計餘額)、**日記帳**(依日期的分錄流水)。只計**已過帳**的傳票,金額為新台幣。

### 9.5 財務報表與年度結帳

**財務報表**(會計 → 財務報表):
- **損益表**:選期間,列營業收入、營業成本、營業毛利、營業費用、營業外收支、所得稅與本期淨利;銷貨退回及折讓已自收入扣除。
- **資產負債表**:選截止日,列流動 / 非流動資產、負債與權益,並檢查資產 = 負債 + 權益(不平衡會出現紅色警告)。
- **現金流量表**(直接法):選期間,列營業 / 投資 / 融資活動的現金流入流出,以及本期淨增減、期初與期末現金及銀行存款。「現金」指拋轉規則裡設定的現金與銀行存款科目;每張傳票的現金增減依對方科目分類(收入費用與 11xx / 21xx 科目為營業、12xx 以後的資產為投資、權益與 22xx 以後的負債為融資)。若淨增減與現金科目餘額對不上,頁面會出現警告。
- **部門別損益**:選期間,依傳票明細的「部門」欄分組列出收入、成本、費用與損益;沒填部門的(含系統自動拋轉的傳票)歸在「未指定部門」。
- 損益表、資產負債表、現金流量表都可勾「與去年同期(日)比較」並**匯出 Excel**;只計已過帳傳票。
- 科目歸在哪一區,看科目類別與代號:11 開頭為流動資產、21 開頭為流動負債、49 營業外收入、7 開頭營業外費損、8 開頭所得稅。**自訂科目請依這個編碼慣例命名**,才會出現在正確的區段。

**年度結帳**(會計 → 會計期間 下方):年度結束後,把當年度損益結轉到保留盈餘。
- 產生一張 12/31 的結帳傳票:收入、成本、費用科目結清,差額轉入保留盈餘(科目在拋轉規則的「年度結帳:保留盈餘」設定)。
- 結帳**不影響損益表**(仍看得到當年度收支);資產負債表的「未結轉損益」會變成保留盈餘,兩種情況都會平衡。
- 只能結已結束的年度;需有關帳權限;可「撤銷」(沖銷結帳傳票)。
- **結帳傳票日期是 12/31,所以 12 月的會計期間必須是「開放」**:正確順序是 12 月的單據與傳票都處理完 → 年度結帳 → 再把 12 月關帳。要撤銷年結,也需要 12 月是開放的。
- 年結後若又補了該年度的傳票,新增的損益不會被結轉,會以「未結轉損益」列在資產負債表(仍平衡);請撤銷年結後重做。損益剛好為零的年度也可以結帳(只結清損益科目)。

### 9.6 營業稅申報(401)

會計 → 營業稅申報:選年度與申報期別(每兩個月一期,第 1 期 = 1–2 月),系統彙總成 401 申報書的參考數字,並可**匯出 Excel**(彙總、銷項明細、進項明細、待處理四個工作表)。

- **銷項**:已過帳的出貨與銷貨退回,**必須已登錄發票號碼**,日期以**發票日期**為準。應稅銷售額依買方有無統一編號分「三聯式 / 二聯式」,另列零稅率與免稅;退回已沖減。
- **進項**:已過帳的進貨與進貨退出,**必須有供應商發票號碼**才可扣抵,日期以進貨單日期為準。進貨金額依料品類型分「進貨」與「費用及其他」;零稅率 / 免稅進貨只列金額。
- **待處理**:沒有發票號碼的單據**不會計入**申報,改列在這裡。申報前請先處理——銷項到出貨單「登錄發票」,進項到進貨單補供應商發票號碼。
- **本期應納 / 留抵稅額** = 銷項稅額 − 進項稅額。
- **本期申報輸入**:頁面上方可填「上期累積留抵稅額」(可按「帶入上一期留抵」)、「海關代徵營業稅額」,兼營免稅時勾「按比例扣抵」(比例 =(應稅 + 零稅率銷售額)÷ 銷售額總計)。按「儲存並重算」後,下方「申報稅額」依 **(進項稅額 + 海關代徵) × 扣抵比例** 算出可扣抵稅額、本期應納稅額與本期累積留抵稅額。填寫需要「傳票過帳」權限。
- **限制**:這是依系統資料彙總的參考數字,不含固定資產進項與特種稅額。正式申報請由會計核對後自行填報。

**媒體申報檔(第一版)**:同一頁下方「媒體申報檔」按「檢查申報檔」,系統依財政部規格產出進銷項申報檔(檔名為統一編號.TXT)。

- 使用前須先在 **系統管理 → 公司資料** 填**統一編號**與**稅籍編號**(營業稅申報書上的 9 碼稅籍編號)。
- **進貨單**要填「憑證種類」(三聯式 / 電子計算機、二聯式收銀機、三聯式收銀機或電子發票)、「發票號碼」(2 碼英文字軌加 8 碼數字)與「發票日期」,供應商要有統一編號,進項才會納入申報檔。
- 本版涵蓋:銷項三聯式 / 二聯式的應稅與免稅;進項應稅的進貨及費用。**退回折讓、零稅率、免稅進貨、固定資產、彙總登錄、作廢發票不在檔案內**,檢查結果會列出「未納入」的單據與原因,這也是申報檔與 401 彙總不同的地方。
- **下載後請先用財政部提供的媒體申報檢核軟體驗證,通過才上傳;本系統產出的檔案尚未經過官方檢核。**

**外幣期末重估**(會計 > 外幣重估,需關帳權限):每月底可把外幣應收、應付依月底匯率重估,差額記入「未實現兌換利益 4903 / 損失 7103」。選期間先「試算」,確認後「執行重估」。規則:一定要依期間順序做(不能跳過前面的月份)、期間結束後才能做、該日要有匯率;下一次重估時系統會自動把上一次沖回(沖回日為新期間第一天)再重新估算;做錯可「撤銷」最近一次。收付款時實際發生的匯兌損益仍照原方式計算,不會重複認列。

**專案**:會計 > 專案可維護專案主檔,手動傳票的每一行可指定專案;財務報表「專案別損益」依專案彙總收入、成本、費用,沒填專案的歸「未指定專案」。

### 9.7 會計期間關帳

會計 → 會計期間。**關帳**後該月:單據不能過帳 / 反過帳(連不產生傳票的庫存單據也不行)、不能新增傳票。
關帳前該月不能有草稿傳票;不能關未來的月份。需要更正時由有權限的人**重開**,改完再關。

## 10. 每月結帳流程

建議每月初依序進行(**順序很重要**):

1. **處理完上月單據**:首頁「待處理單據」清空;該月該過帳的都已過帳;草稿傳票過帳或作廢。
2. **月結成本**(庫存 → 月結成本):按上個月的「月結」。
   - 月加權平均:平均成本 =(期初金額 + 本月進貨金額)÷(期初數量 + 本月進貨數量);出貨、退回、盤點、調整都以此計價。
   - 自動產生兩張傳票:**銷貨成本**(借 銷貨成本、貸 存貨)與**存貨盤損益**;並把平均成本回寫到庫存流水帳。
   - 月結須**依月份順序**進行,且只能結已結束的月份。**月結後該月的庫存異動被鎖定**(進貨 / 出貨的過帳與反過帳都不行)。
3. **對帳檢查**(會計 → 對帳檢查):確認存貨、應收、應付與總帳一致、庫存現有量與流水帳一致、傳票借貸平衡。有「異常」先查清楚再繼續。
4. **會計期間關帳**(會計 → 會計期間):該月的傳票已齊全後關帳。
5. 看試算表與帳齡報表,作為月報。

**要更正已結的月份**:順序相反——先**重開會計期間**,再**取消月結成本**(只能取消**最新**的一個月,會沖銷成本傳票、解除庫存鎖定),修正單據後重新月結、再關帳。

## 11. 資料匯入(上線與期初)

系統管理 → 資料匯入。每種類型都有 **下載範本**(標題列不可修改;有「說明」與「範例」兩頁)。

**流程**:選類型 → 填好 Excel → 上傳 → **預檢**(列出每一列每個欄位的所有問題,**不寫入**)→ 修正後重新預檢 → 通過才能**確認匯入**。任何一列有錯,**整批都不會寫入**。

| 類型 | 說明 |
|---|---|
| 料品、客戶、供應商 | 主檔。預設**已存在的代號視為錯誤**;上傳前把「已存在的代號」改選**覆蓋更新**,就會改為更新既有資料——**空白欄位保留原值**(所以不能用匯入把欄位清空);既有料品的基本單位、類型、批號管理不可由匯入修改。料品範本有「預設倉庫代號」與「多單位換算」(格式 `BOX=12;PKG=144`,表示 1 箱 = 12 個基本單位;覆蓋更新時有填才會取代原有換算) |
| 倉庫、料品分類 | 只能新增(已存在的代號視為錯誤)。倉庫可設允許負庫存、使用儲位;分類可指定上層分類(須已存在或排在前面) |
| 期初庫存 | 倉庫、料號、數量(基本單位)、**單位成本**。只能匯入**尚無庫存異動**的料品;月結成本時視同進貨 |
| 期初應收 / 應付 | 逐筆未沖帳款:對象、單據號碼、單據日期、到期日、幣別、含稅未沖金額。匯入後可照常收付款沖帳 |
| 期初科目餘額 | 各科目借方或貸方餘額(整數元),**借貸合計必須相等**;產生一張已過帳傳票,一次只能有一批有效 |

**期初資料需指定「期初日期」**(通常是上線前一天或上期期末),所有金額都是那一天的餘額。

**建議順序**:倉庫 / 料品分類 → 料品 / 客戶 / 供應商 → 期初庫存 → 期初應收、應付 → 期初科目餘額 → **對帳檢查**,確認存貨、應收、應付與總帳全部「正常」。
期初資料**可以整批撤銷**(匯入紀錄 → 撤銷):已被收付款沖帳、已月結成本、期間已關帳的無法撤銷。主檔不支援整批撤銷,請直接在畫面修改或停用。

## 12. 常見訊息與處理

| 訊息 | 意思 / 怎麼辦 |
|---|---|
| 庫存不足:… | 該倉庫現有量不夠。確認數量與倉庫、先進貨 / 調整,或(有權限者)將倉庫設為允許負庫存 |
| 倉庫盤點中(盤點單 …) | 有進行中的盤點單,該倉庫的庫存異動被凍結;盤點單過帳或作廢後解除 |
| 該月份已月結成本,不可異動庫存 | 成本已定案;需由有權限的人先取消最新的月結(第 10 節) |
| 會計期間 … 已關帳 | 該月已關帳;需先重開會計期間 |
| 超過信用額度 | 客戶的未收應收 + 未出貨訂單 + 本單超過額度;先收款、調整訂單,或請有權限者調整額度 |
| 超過訂單的未交 / 未出貨量、超過可退量 | 累計數量不可超過來源單據的剩餘量;已有別張單據用掉了額度 |
| 目前單據狀態不允許此操作 | 單據狀態已變(可能被別人處理了),重新整理後再看 |
| 他人已修改,請重新整理 | 版本衝突,見 3.1 |
| 已有進貨單 / 出貨單 / 退回單,請先作廢…;若不再進貨改用結案 | 有下游單據時,不能取消核准或作廢上游單據 |
| 應付 / 應收已有付款單 / 收款單沖帳或引用 | 先作廢或反過帳收付款單,才能反過帳來源單據 |
| 借貸不平衡 | 傳票過帳要求借方合計 = 貸方合計 |
| 請求過於頻繁(429) | 短時間操作太多,稍等再試;經常發生請洽管理員調整限流 |
| 沒有權限 | 你的角色沒有這項動作,洽管理員 |
