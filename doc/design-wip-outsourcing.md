# 設計草案:在製品(WIP)與委外加工(待確認,尚未實作)

## 問題
- 目前工單(D94)領料與成品入庫發生在「完工回報」同一個交易,完工前材料仍算在原料倉,**沒有在製品**概念。
- 沒有委外加工:材料送去外面加工廠、收回半成品 / 成品、付加工費,目前只能手動用調撥 + 採購湊,帳上看不出材料在誰手上、成本也不會自動歸到成品。

## 範圍(建議分兩階段,先做 A)
- **A. 委外加工單**:發料給加工廠 → 收回成品(可分批)→ 加工費轉應付。
- **B. 在製品(WIP)**:一般工單可先「領料」再「完工」,中間的材料列為在製品。B 依賴 A 的「領料不等於完工」機制,所以放第二階段。
- 不做:多工序途程(routing)、工時 / 機台、委外料損耗追蹤到批號以外、加工廠庫存對帳單。

## A. 委外加工單
### 流程
1. 建立委外單(單號 `SC`):加工廠(供應商)、成品料品、預計收回量、發料倉、收回倉、預計加工費單價、預計收回日;材料明細預設帶成品 BOM(可改,同工單)。
2. **發料**:每次發料過帳,材料從發料倉轉入該加工廠的**委外倉**(新增倉庫類型 `subcontract`,一廠一倉,建加工廠時可自動建立)。庫存仍屬公司,因此存貨金額不變,只是位置在外。
3. **收回**:填收回日、數量、成品批號 / 效期 / 儲位、實際加工費、實際耗料(預設依 BOM × 收回量,從委外倉扣)。過帳時同交易:委外倉扣材料、成品入收回倉。
4. **加工費**:收回時產生一筆「應付加工費」(沿用採購發票 / 應付模組,以勞務類料品或專用科目),不另造付款流程。
5. 累計收回達預計量自動結案;未達可手動結案(剩餘材料可「退料」回發料倉)。作廢收回 / 發料沿用 D94 的沖銷方式。

### 資料表(migration 000041)
- `warehouses` 加 `kind`(`normal` | `subcontract`)與 `vendor_id`(委外倉對應供應商);委外倉不出現在一般出貨 / 銷售倉選單。
- `subcontract_orders`、`subcontract_order_lines`(材料標準用量)。
- `subcontract_transactions`(發料 / 收回 / 退料)與明細:類型、日期、數量、批號 / 儲位、加工費。
- 庫存來源類型新增 `sc_issue` / `sc_receive` / `sc_return`,來源 id = 交易 id。

### 成本
- 材料成本沿用月結平均成本;發料轉倉不改變單價。
- 收回成品成本 = 實際耗料成本 + 實際加工費(與工單月結算法一致,月結時把委外收回視同完工,加工費取交易的實際加工費)。
- 成本差異報表(D97)把委外收回納入「完工量 / 實際加工費」。

### 簽核與權限
- 委外單沿用單據簽核(D61);發料 / 收回回報沿用過帳權限,不另走簽核(同 D94)。
- 新權限:`production.subcontract.view/edit/post`。

### MRP
- 在途量:未收回的委外量視同在途工單;材料需求:未發料的材料計入毛需求;委外倉庫存不算可用量(已在外面)。

## B. 在製品(WIP)
- 工單新增「領料」動作(`wo_issue_only`),可在完工前分批領料,材料從原料倉轉入該工單的 **WIP 虛擬倉**(每公司一個 `wip` 倉,以工單 id 為批次維度追蹤)。
- 完工回報改為從 WIP 倉扣料(沒領料才直接從原料倉扣,維持 D94 行為,向下相容)。
- 報表:在製品清單(工單、已領料金額、已完工回沖、餘額);資產負債表存貨科目含 WIP(目前 GL 無此科目,需先決定是否另設「在製品」科目)。
- 風險:月結成本、MRP、批號追溯都要認得 WIP 倉,改動面比 A 大,建議 A 驗證穩定後再做。
