## 檔案規則

- 檔名:`營利事業統一編號(8 碼).TXT`;每筆記錄固定 81 字元(Bytes);一筆一行。
- 進項、銷項(含退回折讓)放在同一個檔案。

## 欄位語意(要點第二十點)

- **資料所屬年月**:憑證(或退貨折讓證明單)開立的年月,民國年 3 碼 + 月 2 碼。
- **課稅別**:1 應稅、2 零稅率、3 免稅、F 作廢發票、D 空白未使用發票(F / D 時其餘欄位依附件以空白或零補足)。
- **扣抵代號**:1 進項可扣抵進貨及費用、2 進項可扣抵固定資產、3 進項不可扣抵進貨及費用、4 進項不可扣抵固定資產、空白 = 銷項。
- **營業稅額**:單位元;銷售額已含稅或特種稅額者填零。
- **彙加註記**:A 彙加資料、B 進項分攤(僅格式代號 25)、空白 = 非彙加。
- **通關方式註記**:1 零稅率、非經海關出口、須附證明之銷項;2 零稅率、經海關出口、免附證明;空白 = 進項、退折證明單、非零稅率銷項。
- 流水號:依順序編號,不得重複。

## 第一版的實作決定(M11)

- 涵蓋:銷項 31(買方有統編)/ 32(無統編),課稅別 1 應稅或 3 免稅;進項 21 / 22 / 25,課稅別 1、扣抵代號 1。
- **進項記錄的 24–31(買受人)留空、32–39 填供應商統編;銷項記錄 24–31 填買方統編(二聯式留空)、32–39 留空**——依欄位語意(「銷售人統一編號」為進項憑證的賣方統編、「買受人統一編號」無統編則補空白)判讀,**未經檢核軟體驗證**。
- 流水號 7 碼補零、從 0000001 連續編號(銷項在前、進項在後,各自依日期與單號);資料所屬年月為發票日期的民國年月;金額四捨五入為整數元;檔名「統一編號.TXT」;每筆以 CRLF 結尾。
- 不產生記錄、改列「未納入」清單:退回折讓、零稅率銷項、免稅 / 零稅率進貨、沒有憑證種類的進貨、供應商無統編、發票格式不符、金額超出欄位長度。

## 原本列出的、實作前需要補的資料(第一版已處理 1–3,其餘仍待辦)

系統目前**沒有**這些資料,實作前要先補欄位或確認做法:

1. **公司稅籍編號(9 碼)**與公司統一編號(8 碼,用於檔名):公司資料需有欄位並驗證。
2. **進項憑證種類**:21(三聯式)、22(二聯式收銀機)、25(三聯式收銀機 / 電子發票)無法由現有資料判斷,進貨單需新增「憑證種類」。
3. **進項發票的字軌與號碼拆分、發票日期**:進貨單目前只有一個自由文字的 `invoice_no`(最長 20 字),沒有發票日期,資料所屬年月現在以進貨單日期代替;需改為 2 碼字軌 + 8 碼號碼並驗證,補發票日期。
4. **進項扣抵代號**:固定資產(2、4)與進貨及費用(1、3)的區分,現有料品類型只有商品 / 服務;不可扣抵(3、4)的判斷也沒有欄位。
5. **進貨退出、銷貨退回(格式 23/24/33/34)**:規格要求「折讓證明單」逐筆,但系統目前的退回單沒有折讓證明單號碼、也沒有對應原發票的欄位,需先確認這些欄位該填什麼。
6. **銷項電子發票(35)**:系統目前把發票視為手動登錄,沒有區分三聯式 / 二聯式 / 電子發票,暫以「買方有無統編」對應 31 / 32。
7. 稅額 500 元以下彙總(26 / 27)為**可選**,可不實作而逐張列。
8. 零稅率銷售額另需「零稅率銷售額資料檔」(附件十,副檔名 T02),通關方式註記也依出口類型填寫;系統目前沒有出口資訊。
9. **驗證**:財政部網站有媒體申報檢核用的免費軟體(<https://www.etax.nat.gov.tw/etwmain/form-and-file-download/freeware>),產出的檔案必須先通過檢核才能上線;並確認稽徵機關對該公司的媒體申報核准。
